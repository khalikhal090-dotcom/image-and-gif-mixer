GIF + Photo Mixer — PWA starter

PHONE-ONLY PUBLISHING PATH
1. Extract this ZIP on your phone.
2. Create a GitHub account (or use an existing one) and create a public repository.
3. Upload the CONTENTS of this folder to the repository root: index.html, manifest.webmanifest, service-worker.js, and the icons folder.
4. In the repository, open Settings > Pages. Choose Deploy from a branch, select main and /(root), then Save.
5. Wait for GitHub Pages to publish. Open the HTTPS site URL on your phone and test photo/GIF uploads and export.
6. Enter the published HTTPS URL at https://www.pwabuilder.com/ and follow its Android packaging steps. Review the generated package and signing instructions carefully.

IMPORTANT
- This starter caches the app shell. The GIF encoder is loaded from a CDN, so GIF export still needs an internet connection.
- Test on multiple Android devices before release. This is a prototype, not a finished production app.
- Google Play developer registration and publishing must be handled by an adult account holder if the app creator is under 18. Do not enter a false birth date or use someone else's account without their permission.
- Google Play may require closed testing for new personal developer accounts; check the current Play Console requirements before paying or submitting.
- Play Store submission also needs store listing text, screenshots, a privacy policy, content rating, app access details, and an Android App Bundle (AAB).
